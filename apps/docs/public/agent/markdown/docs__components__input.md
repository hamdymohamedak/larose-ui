# Input

Category: Forms

## Props
- `acceptDrop` (boolean) — Accept plain-text drops into the field.
- `error` (string | null)
- `expansionTooltip` (boolean) — macOS-style expansion tooltip when truncated text overflows the field.
- `format` (FieldFormat) — Formats numeric values on blur (currency, percent, number).
- `formatOptions` (FormatFieldOptions)
- `hint` (string)
- `inputSize` (Size)
- `label` (string)
- `loading` (boolean)
- `required` (boolean) — Shows a required indicator and sets the native required attribute.
- `state` (UIState)
- `validate` (FieldValidator) — Validates on blur or change and surfaces inline feedback immediately.
- `validateOn` ('blur' | 'change')
