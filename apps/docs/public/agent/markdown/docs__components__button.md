# Button

Category: Actions

## Props
- `buttonRole` (ButtonRole) — Apple HIG semantic role — affects appearance in alerts and sheets.
- `error` (string | null)
- `flexible` (boolean) — macOS flexible-height push button for multi-line content.
- `fullWidth` (boolean) — watchOS-style full-width primary actions.
- `iconOnly` (boolean)
- `leftIcon` (ReactNode)
- `loading` (boolean)
- `loadingLabel` (string) — Alternative label shown while loading (Apple HIG activity indicator pattern).
- `opensAnotherView` (boolean) — macOS: append trailing ellipsis when the button opens another view.
- `rightIcon` (ReactNode)
- `shape` (ButtonShape) — Capsule (default), circle (icon-only), or roundedRect (vertical stacks).
- `size` (Size)
- `state` (UIState)
- `tooltip` (string) — macOS / visionOS hover tooltip.
- `variant` (Variant)
