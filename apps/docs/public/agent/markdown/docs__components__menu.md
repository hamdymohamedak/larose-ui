# Menu

Category: Navigation

## Props
- `dimBackground` (boolean)
- `enableMnemonics` (boolean) — Enable Alt+key mnemonics while open. Defaults to true.
- `enableShortcuts` (boolean) — When true, keyboard shortcuts activate menu items while open. Defaults to true.
- `enableTypeAhead` (boolean) — Enable type-ahead letter matching while open. Defaults to true.
- `entries` (MenuEntry[])
- `layout` (MenuLayout)
- `mnemonicVisible` (boolean) — When true, underline mnemonic access keys in labels.
- `onEntrySelect` ((entry: MenuItemConfig) => boolean | void)
- `onOpenChange` ((open: boolean) => void)
- `open` (boolean)
- `optionKey` (boolean) — Passed from MenuBar for Option-key alternate accelerators.
