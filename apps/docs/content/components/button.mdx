# Button

Buttons trigger actions. laRose follows Apple HIG patterns for roles, sizing, and alert layouts.

## Usage

```tsx
import { Button } from '@larose-ui/react';

<Button variant="primary" onClick={() => save()}>
  Save changes
</Button>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'primary' \| 'secondary' \| 'outline' \| 'ghost' \| 'destructive'` | `'primary'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `buttonRole` | `'normal' \| 'primary' \| 'cancel' \| 'destructive'` | `'normal'` | Semantic role in alerts |
| `loading` | `boolean` | `false` | Shows activity indicator |
| `disabled` | `boolean` | `false` | Disables interaction |
