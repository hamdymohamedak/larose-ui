# @larose-ui/playground (Storybook)

**Role:** documentation, component catalog, visual reference, and React-oriented component development.

**Not** the authority for multi-framework parity. That stack is:

| Layer | Command |
|-------|---------|
| Cores + adapters | `pnpm test` |
| Kitchen-sink apps | `pnpm sandbox:react\|vue\|svelte` |
| Critical user flows | `pnpm test:parity` |
| Architecture | `pnpm doctor:ci` |

See `apps/sandbox-shared/TESTING.md`.
