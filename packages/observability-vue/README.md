# @larose-ui/observability-vue

> UX observability for Vue — journeys, funnels, rage clicks.

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/observability-vue
# or
pnpm add @larose-ui/observability-vue
# or
yarn add @larose-ui/observability-vue
```

**Peer dependency:** `vue >=3`

## Quick start

```tsx
import { ObservabilityProvider } from '@larose-ui/observability-vue';
```


## Features

- Journey tracking
- Observed form helpers
