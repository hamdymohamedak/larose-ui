# @larose-ui/permissions-svelte

> Authorization-aware Svelte UI (RBAC / ABAC).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/permissions-svelte
# or
pnpm add @larose-ui/permissions-svelte
# or
yarn add @larose-ui/permissions-svelte
```

**Peer dependency:** `svelte >=5`

## Quick start

```tsx
import { Can } from '@larose-ui/permissions-svelte';
```


## Features

- `<Can>` + permission store
