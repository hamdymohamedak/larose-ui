# @larose-ui/devtools-svelte

> In-app runtime inspector for Svelte (development only).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/devtools-svelte
# or
pnpm add @larose-ui/devtools-svelte
# or
yarn add @larose-ui/devtools-svelte
```

**Peer dependency:** `svelte >=5`

## Quick start

```tsx
import { DevToolsPanel } from '@larose-ui/devtools-svelte';
```


## Features

- DevTools panel
- Runtime / observability bridge
