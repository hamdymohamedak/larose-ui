# @larose-ui/devtools-react

> In-app runtime inspector for React (development only).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/devtools-react
# or
pnpm add @larose-ui/devtools-react
# or
yarn add @larose-ui/devtools-react
```

**Peer dependency:** `react >=18`

## Quick start

```tsx
import { DevToolsProvider } from '@larose-ui/devtools-react';
```


## Features

- Runtime context panel
- Event timeline
- Component inspector
