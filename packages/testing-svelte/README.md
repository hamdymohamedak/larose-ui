# @larose-ui/testing-svelte

> Svelte test helpers aligned with the laRose matrix.

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/testing-svelte
# or
pnpm add @larose-ui/testing-svelte
# or
yarn add @larose-ui/testing-svelte
```

**Peer dependency:** `svelte >=5`

## Quick start

```tsx
import { defaultTestMatrix } from '@larose-ui/testing-svelte';
```


## Features

- Shared test matrix
- Svelte helpers
