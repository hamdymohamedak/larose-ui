# @larose-ui/testing-vue

> Vue test helpers aligned with the laRose matrix.

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/testing-vue
# or
pnpm add @larose-ui/testing-vue
# or
yarn add @larose-ui/testing-vue
```

**Peer dependency:** `vue >=3`

## Quick start

```tsx
import { resolveVueMatrixOptions } from '@larose-ui/testing-vue';
```


## Features

- Shared test matrix
- Vue matrix helpers
