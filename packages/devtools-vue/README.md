# @larose-ui/devtools-vue

> In-app runtime inspector for Vue (development only).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/devtools-vue
# or
pnpm add @larose-ui/devtools-vue
# or
yarn add @larose-ui/devtools-vue
```

**Peer dependency:** `vue >=3`

## Quick start

```tsx
import { DevToolsPanel } from '@larose-ui/devtools-vue';
```


## Features

- DevTools panel
- Runtime / observability bridge
