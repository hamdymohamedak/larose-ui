# @larose-ui/ai-react

> Permission-bound AI UI for React (SmartTable / SmartForm).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/ai-react
# or
pnpm add @larose-ui/ai-react
# or
yarn add @larose-ui/ai-react
```

**Peer dependency:** `react >=18`

## Quick start

```tsx
import { AIProvider, SmartTable } from '@larose-ui/ai-react';
```


## Features

- NL table filtering
- NL form fill
- Permission-gated actions
