# @larose-ui/data-svelte

> Svelte data controllers with self-healing errors and undo.

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/data-svelte
# or
pnpm add @larose-ui/data-svelte
# or
yarn add @larose-ui/data-svelte
```

**Peer dependency:** `svelte >=5`

## Quick start

```tsx
import { createQuery, DataView } from '@larose-ui/data-svelte';
```


## Features

- Query / mutation controllers
- DataView + UndoToast
