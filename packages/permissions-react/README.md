# @larose-ui/permissions-react

> Authorization-aware React UI (RBAC / ABAC).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/permissions-react
# or
pnpm add @larose-ui/permissions-react
# or
yarn add @larose-ui/permissions-react
```

**Peer dependency:** `react >=18`

## Quick start

```tsx
import { Can } from '@larose-ui/permissions-react';
```


## Features

- `<Can>` / `<Permission>`
- Hidden, disabled, readonly fallbacks
