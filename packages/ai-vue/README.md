# @larose-ui/ai-vue

> Permission-bound AI UI for Vue (SmartTable / SmartForm).

**Docs:** [https://hamdymohamedak.github.io/larose-ui](https://hamdymohamedak.github.io/larose-ui/) · **Source:** [laRose UI](https://github.com/hamdymohamedak/larose-ui)

**Public API layer:** Features

## Install

```bash
npm install @larose-ui/ai-vue
# or
pnpm add @larose-ui/ai-vue
# or
yarn add @larose-ui/ai-vue
```

**Peer dependency:** `vue >=3`

## Quick start

```tsx
import { AIProvider, SmartTable } from '@larose-ui/ai-vue';
```


## Features

- SmartTable / SmartForm
- Permission-gated actions
