# @larose-ui/migration

> Codemods, generators, and release intelligence.

Part of **[laRose UI](https://github.com/hamdymohamedak/larose-ui)** — the UI Operating System for modern SaaS applications.

## Install

```bash
npm install @larose-ui/migration
# or
pnpm add @larose-ui/migration
# or
yarn add @larose-ui/migration
```



## Quick start

```tsx
import { applyCodemods, runGenerator } from '@larose-ui/migration';

const code = runGenerator('feature', 'EmployeeList');
```

## Features

- Safe codemods (tokens, provider imports, toast path)
- Scaffolds for forms, pages, and features
- Monorepo release readiness reports
